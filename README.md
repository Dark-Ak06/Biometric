## Описание выполненных работ

### Занятие 1. Введение в биометрические системы. Подготовка среды
- Настройка виртуального окружения (Python, OpenCV, NumPy, Matplotlib, scikit-learn, scikit-image).
- Захват тестового кадра с веб-камеры.
- Сравнительный анализ биометрических модальностей (лицо, отпечаток пальца, голос, радужка глаза).

### Занятие 3. Проектирование системы биометрического контроля доступа
- Проектирование архитектуры двухфакторной СКУД (RFID + лицо RGB/NIR) в режиме верификации 1:1.
- Блок-схемы контуров **Enrollment** и **Verification** в формате `draw.io` и `PNG`.
- Моделирование угроз (**Threat Modeling**) по 8 точкам атак (Ratha's attack points / ISO 30107).
- Математическое моделирование модуля принятия решения (Decision Module): распределения Score $S$ для «Своих» и «Чужих», кривые ошибок $\text{FAR}(T)$ и $\text{FRR}(T)$, точка $\text{EER} = 3.52\%$ при $T = 0.56$, сравнительный анализ FAR-ориентированного и FRR-ориентированного профилей.

### Занятие 4. Работа с биометрическими датасетами
- Загрузка и подготовка двух разнородных датасетов:
  - **ORL / AT&T Faces:** 40 субъектов по 10 изображений (строгий баланс классов).
  - **Fingerprints FVC:** 25 субъектов по 6–14 изображений (естественный дисбаланс классов).
- Визуализация случайных выборок $4\times 4$ с идентификаторами `subject_id`.
- Расчёт статистик и построение гистограмм распределения по классам.
- Реализация корректного разбиения `train_test_split` по **субъектам** (80/20 Open-Set) и объяснение недопустимости разбиения по изображениям (утечка биометрической идентичности).

### Занятие 5. Распознавание отпечатков пальцев
- Полный pipeline предобработки: подавление шума сенсора, локальное выравнивание контраста (`CLAHE`), бинаризация (Оцу и адаптивная), скелетизация линий до 1 пикселя (`skimage.morphology.skeletonize`).
- Поиск особых точек: классические минуции по числу переходов Рутовица ($CN=1$ — окончания, $CN=3$ — бифуркации) и дескрипторы **ORB**.
- Сопоставление через `cv2.BFMatcher` (норма Хэмминга) на 5 парах Genuine («Свой-Свой») и 5 парах Impostor («Свой-Чужой»).
- Выбор оптимального разделяющего порога $T^* = 0.292$ со 100% точностью классификации.
- Экспериментальное исследование влияния поворота отпечатка на $90^\circ$ и подтверждение инвариантности ORB к вращению.

### Занятие 6. Детекция лиц с использованием OpenCV
- Реализация двух детекторов: классический **Haar Cascade** (Виола-Джонс) и глубокая нейросеть **DNN SSD** (`res10_300x300_ssd` / OpenCV DNN).
- Детекция на видеопотоке в реальном времени с замером FPS (`--webcam`).
- Тестирование на 10 сценах разной сложности (14 истинных лиц Ground Truth): фронтальное, групповые, наклоны $\pm 22^\circ\dots 24^\circ$, слабое освещение, очки, окклюзия, фоновые помехи.
- Расчёт метрик $\text{TP}, \text{FP}, \text{FN}, \text{IoU}$ и бенчмарк скорости:
  - Haar Cascade: $\text{TP}=10, \text{FP}=2, \text{FN}=4$, средний $\text{IoU} = 0.625$, скорость $\mathbf{124.0\text{ FPS}}$.
  - DNN SSD: $\text{TP}=12, \text{FP}=0, \text{FN}=2$, средний $\text{IoU} = 0.744$, скорость $\mathbf{115.3\text{ FPS}}$.
- Эксперимент по влиянию гиперпараметров `minNeighbors` и `scaleFactor` на точность и скорость каскада Хаара.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dark-Ak06/Biometric.git
   cd Biometric
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запуск скриптов:
   ```bash
   # Проверка окружения (Занятие 1)
   python src/test_environment.py

   # СКУД и графики Decision Module (Занятие 3)
   python src/lab03_access_control.py

   # Датасеты, гистограммы и split (Занятие 4)
   python src/load_dataset.py

   # Отпечатки пальцев, сопоставление и поворот 90° (Занятие 5)
   python src/fingerprint_matching.py

   # Детекция лиц, бенчмарк и сравнение методов (Занятие 6)
   python src/face_detection.py
   # Запуск с веб-камерой:
   python src/face_detection.py --webcam
   ```
