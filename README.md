### Шаг 2. Создание виртуального окружения и установка библиотек

#### Для Windows (PowerShell или Командная строка CMD):
```powershell

python -m venv .venv

# 2. Активация окружения:

# 3. Обновление pip и установка всех библиотек:
```

> ```bash
> pip uninstall -y opencv-python opencv-contrib-python
> pip install opencv-contrib-python
> ```

#### Для Linux / macOS (Bash / Zsh):
```bash
# 1. Создание и активация окружения
python3 -m venv .venv
source .venv/bin/activate

# 2. Установка зависимостей
```

## Обзор всех выполненных лабораторных работ

### Занятие 1. Введение в биометрические системы. Подготовка среды
- Развёртывание виртуального окружения (OpenCV, NumPy, Matplotlib, SciPy, Scikit-Learn, Scikit-Image).
- Тестовый захват кадра с веб-камеры и проверка видеопотока.
- Анализ фундаментальных биометрических модальностей.

### Занятие 3. Проектирование системы биометрического контроля доступа
- Проектирование архитектуры двухфакторной СКУД в режиме верификации $1:1$.
- Построение контуров **Enrollment** и **Verification**.
- Моделирование угроз (**Threat Modeling**) по 8 точкам атак Раты.
- Нахождение точки равной вероятности ошибок $\text{EER} = 3.52\%$ при $T = 0.56$.

### Занятие 4. Работа с биометрическими датасетами
- Загрузка и анализ датасетов **ORL Faces** (40 классов) и **Fingerprints FVC** (25 классов).
- Доказательство недопустимости случайного сплита по изображениям (устранение Subject-Level Data Leakage).

### Занятие 5. Распознавание отпечатков пальцев
- Предобработка: CLAHE, бинаризация Оцу, морфологическая скелетизация до 1 пикселя.
- Извлечение минуций (число переходов Рутовица $CN$) и дескрипторов **ORB**.
- Оптимальный порог $T^* = 0.292$, доказательство инвариантности к повороту на $90^\circ$.

### Занятие 6. Детекция лиц с использованием OpenCV
- Сравнение **Haar Cascade** (124.0 FPS) и глубокой свёрточной нейросети **DNN SSD** (115.3 FPS, $\text{IoU} = 0.744$).
- Тестирование на 10 сложных сценах Ground Truth.

### Занятие 8. Голосовая биометрическая аутентификация (MFCC)
- Извлечение 13 мел-кепстральных коэффициентов (MFCC-13) по нелинейной шкале слуха.
- Усреднение эталона Дархана Аканова из $N=3$ фраз, косинусное сопоставление (**Cosine Similarity**).
- Нахождение оптимального порога $T^* = 0.993$ с нулевой вероятностью ошибок ($\text{EER} = 0.0\%$).

### Занятие 9. Предобработка биометрических изображений с OpenCV
- Адаптивная эквализация `CLAHE` против теней, медианная фильтрация шума.
- Аффинное выравнивание лица по глазам (`haarcascade_eye.xml`) до горизонтали $0^\circ$.
- Распознавание `LBPHFaceRecognizer`: выравнивание улучшило дистанцию confidence с 51.8 до 14.5.

### Занятие 10. Расчёт метрик биометрической точности (FAR, FRR, EER)
- Расчёт плотностей распределения Genuine ($\mu = 0.812$) и Impostor ($\mu = 0.384$) на пуле из 100 пар.
- Расчёт кривых $\text{FAR}(t)$ и $\text{FRR}(t)$ с шагом $\Delta t = 0.001$, нахождение $\text{EER} = 0.00\%$.
- Построение ROC-кривой с идеальной площадью $\text{AUC} = 1.0000$.
- Обоснование порогов для банка ($T = 0.650$, $\text{FAR} = 0\%$) и спортзала ($T = 0.550$, $\text{FRR} = 0\%$).

### Занятие 11. Анализ спуфинг-атак и детекция живого лица (PAD / Liveness)
- Моделирование атак фото-предъявления (распечатка) и видео-предъявления (экран смартфона).
- Пассивный метод PAD: дисперсия оператора Лапласа $\text{Var}(\Delta I)$ для отсечения размытия бумажных копий и муара экранов.
- Активный метод Challenge-Response: отслеживание моргания глаз (Blink Detection) за 3 секунды.
- Оценка метрик по ISO/IEC 30107: $\text{APCER} = 0.00\%$, $\text{BPCER} = 0.00\%$.

### Занятие 12. Мультимодальная аутентификация: лицо + голос
- Score-level fusion: нормализация Min-Max оценок лица LBPH и голоса MFCC к интервалу $[0, 1]$.
- Взвешенное суммирование: $S_{\text{fused}} = w_1 S_{\text{face}} + w_2 S_{\text{voice}}$.
- Тестирование химерных атак (своё лицо + чужой голос).
- Превосходство слияния: унимодальные $\text{EER}_{\text{voice}} = 1.95\%$, $\text{EER}_{\text{face}} = 2.10\%$, объединённая система $\text{EER}_{\text{fused}} = \mathbf{0.00\%}$.

### Занятие 13. Биометрическая аутентификация + MFA
- Двухфакторная аутентификация: Фактор 1 (Inherence: лицо/голос) + Фактор 2 (Possession: одноразовый TOTP-код, RFC 6238).
- Формирование QR-кода для приложения Google Authenticator, окно $\pm 30$ с и фильтр защиты от replay-атак.
- Разработка аварийного Fallback-контура при трёхкратном отказе биометрического сенсора.
- Построение полной диаграммы состояний (State Diagram).

### Занятие 14. Защита биометрических данных и приватность (BioHashing)
- Конспект требований GDPR (ст. 9) и Закона РК «О персональных данных»: строгий запрет хранения исходных медиафайлов.
- Реализация схемы **BioHashing**: проекция вектора признаков на случайный ортогональный базис пользовательского ключа $K$ с бинаризацией в BioCode длины 64 бита и вычислением HMAC-SHA256.
- Доказательство свойства **Cancelable Biometrics**: при компрометации ключа $K_1$ выпускается ключ $K_2$, дающий расстояние Хэмминга $\text{HD} \approx 0.43 - 0.50$ (полная взаимная некоррелированность).
- Комплексный мини-аудит системы по 7 критериям Privacy by Design (уровень соответствия: **ВЫСОКИЙ**).
